# Procedencia y créditos

Las seis escenas en vendor/ascii-rest/ y vendor/types.ts proceden de bas3line/ascii (ascii.rest), MIT. Conservamos licenses/ascii-rest.txt y vendor/ascii-rest/provenance.json con el commit de procedencia. El motor, gestión de archivos, controlador, UI y escenas aurora/ocean/space de src/ son código de aplicación propio. opencode-wallpapers (https://github.com/vaprdev/opencode-wallpapers) es una referencia conceptual; no se distribuye código ni assets de ese proyecto.
